# PharmaNexus (by Nexus-Tech Solutions)

Pharmacy Management System — maintained by Nexus-Tech Solutions as **PharmaNexus**.


## Installation Steps (Configuration)
1. Download and unzip the file on your local system.
2. Put the PharmaNexus folder inside your server root directory (e.g. `htdocs` for XAMPP).

## Database Configuration
1. Open phpMyAdmin
2. Create database `pms`
3. Import `pms.sql`
